# Game covers

The original box-art images (≈1,000 PNG files) are third-party copyrighted artwork, so they are not included in this repository.

The application does not need them to run. When a cover is missing, `MainController` falls back to the bundled `src/main/resources/images/placeholder.png`.

To use real covers locally, put PNG files in this folder, named as in the `image_url` column of the games table.
