# U1-7 · Área de rectángulos

**Conceptos:** Nivel 7 (struct + función miembro)

## Enunciado

Define un agregado (struct) de nombre Rectangle capaz de representar rectángulos con base (double width) y altura (double height). Inicializa dos objetos de ese tipo y calcula sus áreas a través de la invocación de una función miembro apropiada. Imprime los resultados en la terminal.
