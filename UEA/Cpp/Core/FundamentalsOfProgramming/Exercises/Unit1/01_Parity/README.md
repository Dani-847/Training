# U1-1 · Comprobación de paridad

**Conceptos:** Nivel 3 (getline, stoi, try/catch) · Nivel 2 (operador %)

## Enunciado

Escribe un programa que lea un número entero desde la terminal y muestre si el número es par o impar.

## Solución

- `solution.cpp`: solución oficial del profesor.

## Ejemplo de ejecución

Datos escritos por el usuario: "17".

Salida de `solution.cpp`:

```text
Inserta un entero: 17
es 17 par?: false
```
