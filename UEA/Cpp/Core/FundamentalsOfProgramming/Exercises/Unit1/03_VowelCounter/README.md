# U1-3 · Contador de vocales en una cadena de caracteres

**Conceptos:** Nivel 3 (getline) · Nivel 4 (for con índice) · Nivel 5 (función que devuelve bool)

## Enunciado

Diseña un programa que lea una frase completa (incluyendo espacios) desde la terminal y cuente cuántas vocales contiene. Muestra el total al final.

## Solución

- `solution.cpp`: solución oficial del profesor.

## Ejemplo de ejecución

Datos escritos por el usuario: "Hola Mundo desde C++".

Salida de `solution.cpp`:

```text
Insert a string: Hola Mundo desde C++
Number of vowels is: 6
```
