# U1-2 · Conversión de temperatura

**Conceptos:** Nivel 3 (stod, formato {:.2f}) · Nivel 5 (función propia) · Nivel 2 (división con double)

## Enunciado

Crea un programa que lea desde la terminal una temperatura en grados Celsius y la convierta a Fahrenheit utilizando la fórmula
Muestra el resultado por terminal.

> Nota: en el campus la fórmula aparece como imagen. Es **F = C · 9/5 + 32**.

## Solución

- `solution.cpp`: solución oficial del profesor.

## Ejemplo de ejecución

Datos escritos por el usuario: "36.5".

Salida de `solution.cpp`:

```text
Introduce una temperatura en Celsius: 36.5
Temperatura en Fahrenheit: 97.70 °F
Bye!
```
